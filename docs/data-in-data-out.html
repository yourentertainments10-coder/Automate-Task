CarTrends CRM · For decision

Data In, Data Out

Two proposed features: CSV Import (get old data into the CRM) and Webhooks (let the CRM swap data with other software automatically). Neither needs an outside company, licence or payment.

A

CSV Import

Upload a spreadsheet (.csv from Excel or Google Sheets) and every row becomes a proper CRM lead — hundreds at once, instead of typing them in one by one.

Today: old enquiries sit in Google Sheets and Excel files. Nobody can search them, nobody owns them, no follow-ups happen.

After: each row is a lead with an owner, a stage and a follow-up date.

How it works: upload the file → match your columns to CRM fields (Mobile No. → Phone) → preview with every error listed → choose what happens to duplicates → import, with a summary and a download of any failed rows. No row is ever saved silently.

Where: an "Import" button on the Leads page. Effort: about one day. Cost: nil.

B

Webhooks

One software automatically messaging another when something happens — replacing the person who copies data between two systems. Two directions:

Incoming — our website → CRM. A customer fills the enquiry form on our site; a lead is created, assigned and notified within seconds. Note: if we simply put a CarTrends-built form link on our website, this already works today and needs nothing new. The webhook is only needed if we want to keep our own form's design.

Outgoing — CRM → other software. When a lead is won, a task is completed or attendance is marked, the CRM tells another system automatically (accounting, payroll, a reporting sheet). Only worth building if we actually run software that should react — if everything lives inside the CRM, this can wait.

Both directions are signed and logged, keys can be revoked by an Admin, and they go live once the CRM is on a public web address. Effort: 1 day incoming, 1–2 outgoing. Cost: nil.

DECIDE

What we need from you

  • Which data to import first — and one real sample file with your actual columns.
  • If an imported phone number already exists: skip, update, or create a new lead?
  • Who owns imported leads — unassigned, auto round-robin, or from a column in the file?
  • Does our website already have its own enquiry form, and where do those enquiries go today?
  • Any other software that should receive CRM events? If none, we skip outgoing webhooks.
Suggested order:
  • CSV import first — highest value, no dependencies.
  • Website enquiries next — start free by sharing the CRM form link.
  • Outgoing webhooks last — only once a receiving system is named.
